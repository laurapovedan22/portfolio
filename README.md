Portfolio de Laura Poveda Nicolás

Web pública
https://laurapovedan22.github.io/portfolio/

Contenido
- index.html: presentación, habilidades, formación académica y proyectos destacados.
- proyectos.html: descripción de mis proyectos, tecnologías utilizadas y resumen en una tabla.
- contacto.html: formulario de contacto con datos personales, información del proyecto y preferencia de respuesta.
- sobre-mi.html: trayectoria personal, línea de tiempo, vídeo, preguntas frecuentes y nivel en tres tecnologías.
- img/: imágenes de los proyectos en WebP y PNG de respaldo, avatar, logo SVG, favicon e imagen para compartir en redes.
El portfolio utiliza HTML, sin CSS propio ni JavaScript. Incluye el enlace a la fuente Nunito de Google Fonts solicitado en la práctica.
